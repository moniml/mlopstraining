# Social Media Addiction Risk Predictor

AI-powered web application that analyzes images and videos to detect phone usage and predict social media addiction risk.

## Live Demo

http://13.53.42.214:5000

## Technologies

- Python
- Flask
- YOLO
- OpenCV
- Scikit-learn
- Docker
- AWS EC2

## Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
